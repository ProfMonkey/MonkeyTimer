# 🐒 MonkeyTimer

一个免费的 **Windows PPT 演讲倒计时工具**。

MonkeyTimer 的目标不是做复杂的 PPT 插件，而是提供一个轻量、独立、容易使用的演讲计时器：

> 设置时间 → 开始倒计时 → 需要时进入演讲模式 → 将大号倒计时悬浮在演示内容上方。

当前版本：**V0.2**

# ⏱️ 普通计时模式

启动程序后，可以输入：

- 分钟
- 秒

例如：

```
5 分钟 30 秒
```

点击「开始」后开始倒计时。

支持：

### 开始

根据当前输入的分钟和秒启动一次新的倒计时。

### 暂停

暂停当前倒计时。

### 继续

从暂停的位置继续倒计时。

### 重置

将计时器恢复到当前设置的初始时间。

### 自动停止

倒计时到：

```
00:00
```

后自动停止。

---

# 🛡️ 输入检查

程序不会直接接受所有输入。

会检查：

- 是否为空
- 是否为非负整数
- 秒数是否在 `0–59`
- 总时间是否大于 0

例如：

```
分钟：abc
秒：10
```

会被拒绝。

又例如：

```
分钟：1
秒：60
```

同样会被拒绝。

---

# 🧠 稳定计时

核心倒计时逻辑使用：

```python
time.monotonic()
```

而不是系统墙上时间。

这样可以避免系统时间被手动调整等情况直接破坏倒计时逻辑。

核心计时器被独立放在：

```
countdown.py
```

因此它不依赖 Tkinter，可以单独进行单元测试。

# 🎤 演讲模式

V0.2 最主要的新功能是**演讲模式**。

点击：

**「演讲模式」**

程序会打开一个独立的演讲倒计时窗口。

它专门用于在 PPT、WPS 或其他演示内容旁边显示剩余时间。

---

## 🔢 巨大白色数字

演讲模式使用非常大的白色数字显示：

```
05:30
```

相比普通窗口，更适合远距离观察剩余时间。

---

## ⬛ 无边框

演讲窗口使用无边框设计：

- 没有普通窗口标题栏
- 没有系统边框
- 画面更加简洁

这样可以减少演示时不必要的窗口元素。

---

## 🪟 Windows 透明背景

在 Windows 下，程序会尝试将演讲模式的黑色背景设置为透明。

目标效果是：

```
PPT 内容
    +
白色倒计时数字
```

而不是在 PPT 上方出现一个完整的黑色矩形窗口。

如果系统不支持该透明方式，程序会保留黑色背景作为 fallback，而不会直接让演讲模式崩溃。

---

## 📌 置顶

演讲模式会使用窗口置顶逻辑，让倒计时尽可能保持在其他窗口上方。

当前实现会在窗口映射、恢复等情况下重新应用置顶状态。

**完整的 PPT/WPS 全屏兼容性仍需要在实际演示环境中继续验证。**

---

## 🖱️ 鼠标拖动

演讲模式没有标题栏，因此不能像普通 Windows 窗口一样拖动标题栏。

V0.2 改为：

**按住倒计时数字区域 → 拖动鼠标**

即可移动整个演讲窗口。

程序会记录鼠标抓取位置，因此拖动时会保持相对位置，不会突然跳动。

---

## ⎋ Esc 退出

进入演讲模式后，可以使用：

```
Esc
```

退出演讲模式并返回普通窗口。

由于不同 Windows 窗口焦点环境可能影响键盘事件，Esc 的最终可靠性仍建议在实际 PPT/WPS 全屏环境中继续验证。

# 🚀 Windows 运行

需要：

- Windows
- Python 3
- Tkinter

在项目目录打开 PowerShell：

```powershell
py monkey_timer.py
```

如果系统没有 `py` 启动器，也可以：

```powershell
python monkey_timer.py
```

---

# 📦 打包 Windows EXE

项目已经提供：

```
build_exe.bat
```

在 Windows 项目目录运行：

```bat
build_exe.bat
```

脚本会：

1. 检查 PyInstaller
2. 如果没有安装，则尝试通过 pip 安装
3. 使用 `--onefile`
4. 使用 `--windowed`
5. 生成：

```
dist\MonkeyTimer.exe
```

其中 `--windowed` 用于让最终程序以 GUI 应用形式运行，而不是额外打开控制台窗口。

**注意：**

```
build/
dist/
*.spec
```

已经加入 `.gitignore`。

因此 GitHub 仓库保存的是**源码和打包脚本**，而不是构建产生的临时文件。
